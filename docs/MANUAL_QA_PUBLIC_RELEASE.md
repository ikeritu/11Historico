# Manual QA — Public Release

Checklist manual para validar que Once histórico Zurigorri se entiende y se puede jugar como producto público, no solo como proyecto técnico.

## Preparación

- Abrir la versión online en escritorio.
- Abrir la versión online en móvil real o emulación 360–430px.
- Limpiar o anotar si existe partida guardada previa.
- Confirmar que la portada explica el juego sin leer documentación externa.

## Portada

- [ ] Se entiende el mensaje: construir un Athletic histórico y sobrevivir temporada a temporada.
- [ ] El botón principal `Jugar carrera` destaca sobre el resto.
- [ ] `Cómo funciona` explica objetivo, Game Over, supervivencia, palmarés y Europa.
- [ ] `Ver ranking` es visible.
- [ ] En móvil no hay scroll horizontal ni botones cortados.

## Carrera completa — caso básico

- [ ] Iniciar carrera desde cero.
- [ ] Elegir formación.
- [ ] Completar draft de 11 jugadores.
- [ ] Elegir entrenador.
- [ ] Simular temporada completa.
- [ ] Confirmar que el objetivo de temporada se entiende.
- [ ] Confirmar que el resultado explica si se sobrevive o hay Game Over.

## Carrera con Europa

- [ ] Conseguir clasificación europea.
- [ ] Comprobar que se crea torneo europeo en la siguiente temporada.
- [ ] Simular partidos europeos.
- [ ] Validar que semifinal/final aparecen como eventos importantes.
- [ ] Si se gana final europea, confirmar que el título suma al palmarés al cerrar temporada.

## Game Over

- [ ] Provocar o alcanzar Game Over.
- [ ] Revisar resumen final.
- [ ] Confirmar que aparecen temporadas, palmarés y puntos.
- [ ] Confirmar que se puede volver a jugar.

## Ranking

- [ ] Abrir ranking local.
- [ ] Abrir ranking global.
- [ ] Confirmar que títulos europeos aparecen desglosados si existen.
- [ ] Confirmar que no hay errores visuales en móvil.

## Recarga y persistencia

- [ ] Empezar una carrera.
- [ ] Recargar navegador a mitad de temporada.
- [ ] Continuar partida.
- [ ] Recargar justo tras una final europea si es posible.
- [ ] Confirmar que no se duplican títulos ni recompensas.

## Resultado esperado

La versión pública debe responder claramente a estas preguntas:

- ¿Qué es el juego?
- ¿Qué tengo que hacer?
- ¿Qué pasa si fallo?
- ¿Por qué merece la pena seguir otra temporada?
- ¿Dónde veo mi resultado o ranking?
